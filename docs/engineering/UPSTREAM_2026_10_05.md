## 设置归属

- **会前准备**：本场语言、输入设备、录音、可选增益和匿名说话人、洞察上墙模式。开始按钮固定在底部；未开始时不显示空洞察控制台。
- **本场会议**：语言/设备只读，增益、匿名说话人、本场上墙模式、两个观众窗口入口和私有洞察/审核。桌面宽屏将私有洞察与本场控制并排显示。
- **应用设置**：通用（语言/主题/唤醒/版本）、字幕显示（字号/内容/三种布局/位置/透明度）、本地 AI（模型与运行时、字幕间隔）、记录与统计（文字导出/本机用量）。不包含本场上墙模式、音频设备或录音开关。
- **会议工作台**：已有场次、恢复、引用、审核、编辑、隐藏与发布。公开字幕/公开洞察墙继续各自独立。

缺少模型时给出可操作提示并阻止开始，不再用不可关闭的下载层遮住整个软件。模型已安装、Python 运行环境未就绪时，不引导重复下载权重。模型仅经操作员点击下载。

## 音频与恢复边界

增益先作用于新采集 PCM，再保存录音并进行 VAD/ASR；因此崩溃后未闭合尾段也保留当时的音量。双轨分别处理，增益在回声参考/抵消之前应用，连续录音仍保存回声抵消前的输入，已封口片段保存实际送给 ASR 的 PCM。恢复不对保存的音频再次应用当前增益。默认 1× 兼容旧偏好；非有限值回退 1×，范围限制为 0–3×。

音量波形只发往操作员 `main` 窗口。历史队列限制为 64 个采样块，前端保留 72 个显示点，无音频事件超过 1.2 秒显示等待。削波按峰值检测，避免短脉冲被 RMS 平均掩盖。双轨共用一个增益，波形合并展示两个输入的采样块，尚不提供各轨独立调音。

## 未直接移植的内容

上游 GGUF 使用官方量化模型、校验和、断点续传和固定 llama.cpp 版本，其延迟测试是模型级/受控语音测试。Forum 使用独立 Python/MLX worker、确切片段/修订的持久提交及恢复协议；更换引擎需先接通这些契约，并重新测试真实双轨和长会。不能仅复制下拉框，也不能将上游 Hy-MT2 GGUF 的模型级耗时当作 Forum 端到端延迟。

账户/订阅、语音实验室、French 语种与上游 Windows 发布资源不属于本次论坛工作流。已有源码中保留的语言兼容性不因 UI 聚焦中英文而破坏历史场次。
